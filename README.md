# Czire's Portfolio

A personal Flutter portfolio app built to showcase projects, skills, and creative work using a modern UI and smooth animations.

---

## 📱 About the App

Czire's Portfolio is a Flutter-based **mobile and web** application.  
It uses subtle animations (Flutter Animate) and state management (Riverpod) to present content in a clean, responsive layout.

---

## 🛠 Tech Stack

- Flutter  
- Riverpod  
- Flutter Animate  

---

## ✨ Features

- Modern UI design  
- Smooth animations  
- Responsive layout (mobile & web)  
- Project showcase  
- Simple navigation  
- Lightweight and fast  

---

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed:

- Flutter SDK  
- Android Studio or VS Code  
- Chrome or Edge (for Flutter web)  
- Emulator or physical device  

---

## 📦 Install Dependencies

```bash
flutter pub get
```

## ▶️ Run the app
```bash
flutter run
```

## ⚠️ Issue (Chrome not launching) - Failed to launch browser after 3 tries
- When running:
```bash
flutter run -d chrome
```

## ✅ Workaround: Use Web Server Mode
```bash
flutter run -d web-server
```
